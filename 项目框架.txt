项目名称
校园二手交易微信小程序（SpringBoot + 小程序原生 + Vue 管理后台）
项目核心亮点（写简历重点突出 AI 开发）

    全栈开发：微信小程序客户端 + SpringBoot 后端 + Vue 后台管理系统，标准前后端分离架构
    AI 赋能开发：全程使用 Claude Code 辅助编码、接口设计、SQL 编写、异常调试、文档生成，大幅提升开发效率，掌握 AI 工程化落地流程
    场景贴合高校：面向本校师生闲置物品流转，支持发布商品、聊天私信、订单交易、分类检索、举报审核、数据统计完整业务闭环
    软件工程标准化：完整需求、架构、数据库、测试文档，可作为毕设交付，同时用于实习简历演示

技术栈固定（你选定的全套）

    客户端二选一：微信小程序原生 WXML/WXSS/JS / Uni-app（Vue 语法，多端兼容）
    后端：Java 8/17 + SpringBoot2.7 + MyBatis-Plus + Redis（可选，缓存热门商品）
    数据库：MySQL8.0
    管理后台：Vue2/Vue3 + ElementUI + Axios
    辅助工具：Claude Code（代码生成、重构、排错、文档输出）、Postman 接口测试、Git 版本管理、微信开发者工具

二、系统分层架构（毕设画图 + 简历架构描述）
三层架构：小程序客户端层 → 后端服务层 → 数据持久层，配套独立管理后台

    客户端层（用户端）
    负责页面渲染、微信授权登录、图片上传、商品浏览、下单、私信聊天、个人中心交互
    网关 / 控制层（Controller）
    接收小程序、后台双端请求，参数校验、统一返回格式、权限拦截
    业务层（Service）
    核心业务逻辑：商品发布、订单流程、私信、审核、收藏、搜索推荐
    持久层（Mapper）
    MyBatis-Plus 操作 MySQL，Redis 做缓存优化
    数据层
    MySQL 存储用户、商品、订单、聊天、分类数据；云存储 / 微信素材存储商品图片
